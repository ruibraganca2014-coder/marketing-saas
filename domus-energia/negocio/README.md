# Negócio — Domus Energia

| Ficheiro | O que é |
|---|---|
| `Plano_de_Negocio_Domus_Energia.docx` | Plano de negócio (módulo 7855, partes 1 e 2) |
| `Domus_Energia_Ideia_de_Negocio.pptx` | Apresentação da atividade de grupo (10 perguntas, Ideia → Projeto → Negócio) |
| `plano.js` | Gera o Word. Para mudar valores (obras-tipo, obras por mês, custos fixos, investimento) edita as constantes no topo e corre `node plano.js` (precisa de `npm i docx`). `parte-negocio.js` é a versão de setembro de 2026 e já não é usada |
| `apresentacao.js` | Gera a apresentação (`npm i pptxgenjs`, `node apresentacao.js`) |
